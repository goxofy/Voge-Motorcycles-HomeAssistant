# Security policy

## Supported versions

Security fixes are applied to the latest published version and the default branch.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Report vulnerabilities through a [private GitHub security advisory](https://github.com/goxofy/Voge-Motorcycles-HomeAssistant/security/advisories/new). Do not open a public issue when a report could expose credentials, vehicle identity, location data, account data, or private signing material.

Include only the minimum information needed to reproduce the issue. Remove or replace:

- mobile numbers and passwords;
- password hashes, access tokens, and refresh tokens;
- VINs and complete device, user, SIM, message, or route identifiers;
- coordinates, addresses, route points, and message contents;
- private signing material;
- raw Home Assistant storage and unredacted service responses.

Only test systems and accounts you are authorized to use. Do not perform destructive testing, denial of service, credential stuffing, interception of another person's account, or access outside the authorized scope.
